# camera-pip

**Cosa fa.** Mostra la webcam in una piccola finestra senza bordi, sempre in primo piano, che segue e inquadra il volto. Riavvia la camera se l'immagine si blocca e spedisce un diario diagnostico al server di casa.

**Dove gira.** Sul PC fisso, installata in `%LOCALAPPDATA%\Programs\Camera PiP`, aperta dal menu Start. Si sviluppa in `~/projects/camera-pip`. `npm run publish` pubblica la versione nuova su `home-server…/ota/camera-pip/` e l'app la propone dal suo menu.

**Chi lo usa.** Andrea, durante video call e registrazioni.

**Stato.** In uso, versione 1.17.0.
